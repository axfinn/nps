系统服务管理
说明：安装后会在登录系统时自动启动：隧道自动连接、 本地管理面板就绪，并在状态栏常驻显示端口（macOS 菜单栏 / Windows 托盘）， 点击图标即可打开面板；开机时还会收到一次端口提醒。
默认安装为当前用户的登录自启项，不需要管理员密码； 安装后下次登录生效，当前窗口仍可继续手动使用。
版本升级 / 旧版本清理
平滑升级：会把机器上残留的旧服务、旧进程找出来并停掉卸载， 再原子替换二进制、保留原有连接配置并重启新服务； 任一步失败都会自动回滚到旧版本。也兼容老的命令行版 Npc / nps-client-* 服务，避免新旧客户端抢同一个 vkey。
