# NPS

一款轻量级、高性能、功能强大的内网穿透软件。

# 特性

- 协议支持全面，兼容几乎所有常用协议
- Web 管理界面，方便配置和监控
- 客户端无需配置，直接运行即可使用
- 支持 TCP、UDP、HTTP、HTTPS 等多种协议
- 支持端口映射、域名解析、反向代理等功能

# 快速开始

## 服务端部署

### Linux/Mac

```bash
# 启动
sudo ./nps install
sudo nps start

# 或者直接运行
./nps
```

### Windows

```powershell
# 启动
nps.exe install
nps.exe start

# 或者直接运行
nps.exe
```

## 客户端部署

```bash
# 直接运行（推荐）
./npc -server=你的服务器地址:8024 -vkey=你的vkey

# 安装系统服务
./npc install -server=你的服务器地址:8024 -vkey=你的vkey
```

### Windows 客户端

```
双击 npc.exe，按照提示输入服务器地址和 vkey 即可完成配置。
```

## 邮箱验证码登录与账号权限

### 配置 SMTP

在 `conf/nps.conf` 末尾填写发信参数。**字段名与 devtools 项目的 `config.yaml` 一致**，可直接复制那边 `smtp_host / smtp_port / smtp_user / smtp_pass` 四项；`465` 走隐式 TLS，其它端口在服务端支持时走 STARTTLS，认证使用 SMTP PLAIN。

```ini
email_login_enable=true
smtp_host=smtp.exmail.qq.com
smtp_port=465
smtp_user=noreply@example.com
smtp_pass=你的授权码
smtp_from=                     # 留空则用 smtp_user 作为发件人
email_code_ttl_minutes=10      # 验证码有效期
email_code_resend_seconds=60   # 同一邮箱重发间隔
email_code_max_attempts=5      # 最多错误次数，超出即作废
email_code_ip_limit=10         # 单 IP 每小时发码上限
```

也可通过环境变量覆盖（Docker 部署推荐，避免密码落盘）：`NPS_SMTP_HOST`、`NPS_SMTP_PORT`、`NPS_SMTP_USER`、`NPS_SMTP_PASS`、`NPS_SMTP_FROM`。四项 SMTP 凭据未填齐时，登录页自动退回纯密码登录，不影响原有功能。

### 绑定与使用

1. 超级管理员在「用户与权限」新建/编辑用户时可直接填写邮箱；用户也可登录后到「账号与安全」自助绑定。
2. 自助绑定需向该邮箱发送验证码并完成校验，一个邮箱只能绑定一个账号（大小写不敏感）。
3. 登录页切换「邮箱验证码」标签，获取验证码后即可免密登录；验证码一次性、限时、按用途（登录 / 绑定）隔离。

### 普通用户自助客户端

- 普通用户可在「客户端」页面自行新增客户端，创建后**自动写入 `conf/users.json` 归属本人**，无需超级管理员再分配。
- 普通用户只能查看、编辑、启停、删除自己的客户端及其隧道、域名解析；越权请求在服务端被拦截（不会因前端隐藏按钮而失效）。
- 流量 / 速率 / 连接数 / 隧道数上限以及旧版 Web 登录凭据仍由超级管理员设置；用户级端口范围继续受全局 `allow_ports` 与自身 `AllowPorts` 双重约束。
- 没有任何客户端的普通用户不会看到任何客户端（旧版空归属范围导致的越权查看已修复）。

## Docker 部署

### 服务端

```bash
# 拉取镜像
docker pull axfinn/nps

# 运行容器
docker run -d --name nps \
  -v /etc/nps:/conf \
  -p 8024:8024 -p 8080:8080 -p 8443:8443 \
  axfinn/nps
```

### 客户端

```bash
# 拉取镜像
docker pull axfinn/npc

# 运行容器
docker run -d --name npc \
  axfinn/npc -server=你的服务器地址:8024 -vkey=你的vkey
```

# 配置说明

默认配置文件位于 `conf/nps.conf`，主要配置项：

| 配置项 | 说明 |
|--------|------|
| http_port | HTTP 端口 |
| https_port | HTTPS 端口 |
| bridge_port | 客户端连接端口 |
| vkey | 认证密钥 |
